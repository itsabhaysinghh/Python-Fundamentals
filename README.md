# Python Starter Projects

A small collection of beginner Python exercises created while learning programming fundamentals.

## Projects

| File | Description | Concepts practiced |
|---|---|---|
| `calculator.py` | Command-line calculator | Input handling, conditions, arithmetic |
| `GuessTheNumber.py` | Number guessing game | Loops, comparisons, random numbers |
| `Password Generator.py` | Password generator | Random selection, strings, character sets |

## Requirements

- Python 3

## Run a project

Run any script from the repository directory:

```bash
python calculator.py
python GuessTheNumber.py
python "Password Generator.py"
```

Each script is standalone and can be run independently.

## Purpose

These exercises are small learning projects focused on building confidence with Python syntax, control flow, functions, and the standard library.
